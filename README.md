# Today's Wan! 🐾

毎日違う犬種のワンちゃんに出会える、かわいい癒し系Webサイトです。
HTML / CSS / JavaScriptだけで作られており、データベースや有料APIは使っていません。

## ローカルでプレビューする方法

一番かんたんな方法：

1. このフォルダの中の `index.html` をダブルクリックしてブラウザで開く

うまく表示されない場合（おすすめ方法）：

```bash
# このフォルダの中で実行
python3 -m http.server 8000
```

そのあとブラウザで `http://localhost:8000` を開いてください。

動作確認のコツ：
- `http://localhost:8000/?date=2026-01-05` のように日付を指定すると、その日のワンちゃんを確認できます
- `http://localhost:8000/?dog=corgi` のように指定すると、その犬種の詳細画面を直接開けます

## 文言（名前・性格・メッセージなど）を編集する方法

**`js/data.js` というファイルだけ**を編集すればOKです。

- 犬種名、性格、紹介文、今日のひとこと、テーマカラーが1犬種ずつまとまっています
- 並び順がそのまま日替わりの順番です（1番目が2026年1月1日の担当です）
- 文字を書き換えたら保存して、ブラウザを再読み込みするだけで反映されます
- カンマ（,）や引用符（"）を消してしまうと動かなくなるので、文字の部分だけを書き換えてください

イラストを変えたいときは、`assets/dogs/` の中にある同じ名前のファイル（例：`shiba.svg`）を差し替えてください。

## 仕組み

- 日替わり：日本時間の日付をもとに、「2026年1月1日からの日数 ÷ 12 の余り」でその日の犬種を決めています。同じ日なら誰が開いても同じ犬種になります
- お気に入り：ブラウザの LocalStorage（キー：`todays-wan-favorites`）に保存されます。サーバーには送信されません

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作成します（例：`todays-wan`）
2. このフォルダの中身をすべてアップロードします（フォルダ構成はそのまま）
   - Web画面からアップロードする場合は、`index.html`、`css`、`js`、`assets` フォルダの中身をドラッグ＆ドロップできます
3. リポジトリの **Settings → Pages** を開きます
4. **Build and deployment** の Source で `Deploy from a branch` を選び、Branch は `main` / `(root)` を選んで **Save**
5. 数分待つと `https://（ユーザー名）.github.io/todays-wan/` のようなURLで公開されます

## ファイル構成

```
todays-wan/
├─ index.html       … 画面の土台
├─ css/style.css    … デザイン
├─ js/data.js       … 12犬種のデータ（編集はここだけ！）
├─ js/app.js        … 日替わり・お気に入りなどの処理
├─ assets/dogs/     … 犬種ごとのイラスト（SVG）
└─ README.md        … このファイル
```
